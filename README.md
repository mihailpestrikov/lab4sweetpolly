# Естественные и синтетические научные тексты

## Как запустить

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
brew install libomp   # нужен xgboost на macOS
.venv/bin/jupyter notebook solution.ipynb
```

Прогнать ноутбук сверху вниз. С нуля это около часа: разбор stanza и прогон языковых моделей.
Все промежуточные результаты складываются в cache/, повторный запуск занимает пару минут.
Модели скачиваются с HuggingFace при первом запуске, всего около 6 ГБ.

Данные лежат в репозитории, скачивать ничего не нужно:
- `data/AIGTxt.xlsx` взят с https://data.mendeley.com/datasets/y9bj7734vf/1
- `data/AINL-Eval-2025` это копия https://github.com/iis-research-team/AINL-Eval-2025

## Что где лежит

| Файл | Что это |
|---|---|
| solution.ipynb | Само решение, код и выводы |
| report.pdf | Отчёт на 6 страниц |
| explained.pdf | Подробное объяснение с основ, простым языком |
| profiling_ud.py | Признаки Profiling-UD по UD-разбору, та же номенклатура, что у веб-сервиса |
| semantic.py | BARTScore (порт neulab), LM-статистики, Self-BLEU, distinct-n, MTLD, эмбеддинги |
| prep_data.py | Загрузка и выборка текстов |
| results/profiling_{lang}_{label}.csv | Признаки Profiling-UD по классам |
| results/profiling_ud_input/*.conllu | Разбор по классам, для загрузки в оригинальный Profiling-UD. |
| results/informative_features_{lang}.csv | Статистика по признакам: r_pb, дельта Клиффа, p с поправкой FDR |
| results/classification.csv | Все результаты классификаторов |

## Результат

Macro F1 на 5 фолдах, лучшая из LogReg, SVM, RF и XGBoost:

| Задача | Длина | Profiling-UD | + LM и лексика | TF-IDF | Энтропия + RF |
|---|---|---|---|---|---|
| en: human vs ai | 0.57 | 0.84 | 0.87 | 0.95 | 0.57 |
| en: human / ai / hybrid | 0.37 | 0.59 | 0.63 | 0.67 | 0.37 |
| ru: human vs ai | 0.82 | 0.92 | 0.93 | 0.93 | 0.47 |
| ru: четыре источника | 0.58 | 0.82 | 0.84 | 0.93 | 0.27 |

Столбец «Энтропия + RF» воспроизводит статистический метод из kinit-sk/mgt-detection-benchmark.

## На что посмотреть в первую очередь

**Разные языки, разные признаки.** В английском ИИ-текст получен пересказом, и он отличается словарём
и синтаксисом: слова длиннее, меньше связок и вспомогательных глаголов, больше причастий. В русском
тексты сгенерированы с нуля, поэтому у них короче синтаксические связи, больше сочинения, почти нет чисел.
Доля причастий у двух языков меняет знак.

**Длина в русском.** Человеческие аннотации заметно длиннее. Частная корреляция с поправкой
на длину показывает, что стилистические различия не сводятся к длине. Отдельная базовая линия
«только длина» даёт 0.82 в бинарной задаче, Profiling-UD прибавляет к ней ещё 10 пунктов.

**Шаблонность моделей.** Self-BLEU у русских ИИ-текстов втрое выше, чем у человеческих, и BARTScore
продолжения по первому предложению у них тоже заметно выше. Модели пишут по одной схеме.
